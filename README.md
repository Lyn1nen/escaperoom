# 午夜鐘聲，南瓜學院 · Escape Room

## 專案主題

本專案以「萬聖節校園密室逃脫」為主題，結合校園傳說、萬聖節氛圍與解謎挑戰。玩家將探索神祕校園，與角色互動、蒐集線索並解開謎題，逐步揭開隱藏的故事，找到逃離校園的方法。

## 故事介紹

萬聖夜停電後，林小滿被困在南瓜學院。玩家將與怪奇社一起找回「名字、聲音、約定」三枚校徽碎片，解開三十年前取消舞會的真相，替幽靈學生阿零完成最後一次點名。

阿零並非想傷害大家，只是害怕自己與朋友的約定被遺忘。玩家的解謎成果與最後選擇，將決定故事的結局。

## 遊戲形式

- 單人 2D 網頁密室逃脫。
- 三個章節，每章五關，共十五關。
- 透過觀察場景、閱讀對話、收集線索與操作機關推進故事。
- 支援電腦滑鼠、鍵盤與手機觸控。
- 採萬聖節校園與溫和懸疑風格，不以突發高音量驚嚇為主要玩法。

## 章節介紹

| 章節 | 關卡 | 主要目標 |
| --- | --- | --- |
| 消失的點名簿 | 第 1–5 關 | 找回阿零的名字，取得名字碎片。 |
| 被鎖住的萬聖舞會 | 第 6–10 關 | 還原舞會邀請與留言，取得聲音碎片。 |
| 鐘樓十三響 | 第 11–15 關 | 找回被遺忘的約定，完成最後一次點名。 |

## 玩法與計分

1. 觀察場景並閱讀題面。
2. 選擇或輸入答案，提交解答。
3. 錯誤可重試，也可使用兩級提示。
4. 解開機關後取得線索，前往下一關。
5. 第十五關選擇最後的安排，決定結局。

每關得分：

`100 + 答對次數獎勵 - 提示費用`

| 項目 | 分數 |
| --- | --- |
| 每關基礎分 | 100 |
| 第一次答對獎勵 | +30 |
| 第二次答對獎勵 | +15 |
| 第三次起答對獎勵 | +5 |
| 提示一 | −10 |
| 提示二 | 再 −20 |

每關只計分一次，最高 130 分，全程最高 1950 分。錯答不直接扣分，但會影響答對次數獎勵。

## 結局方向

玩家可選擇：

- 邀全校重辦舞會。
- 送阿零安心離開。
- 請阿零留下。

總分與最後選擇共同決定結局。最後選擇沒有錯誤答案。

## 開發與執行

以下指令適用於遊戲程式及設定檔皆已提交後。

需要 Node.js 22.12 以上及 npm，建議使用 Node.js 24。

```bash
git clone https://github.com/Lyn1nen/escaperoom.git
cd escaperoom
npm ci
npm run dev
```

依終端顯示的位址開啟遊戲。

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 啟動開發伺服器。 |
| `npm test` | 執行遊戲規則及存檔測試。 |
| `npm run build` | 產生正式網站至 dist。 |
| `npm run preview` | 檢查正式打包結果。 |
| `npm run check` | 執行單元測試及建置。 |
| `npm run test:e2e` | 執行瀏覽器操作測試。 |

瀏覽器測試首次使用前：

```bash
npx playwright install chromium
npm run test:e2e
```
